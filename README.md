# ⌨️ গ্লাস কীবোর্ড

গ্লাস-ইফেক্টের সুন্দর Android কীবোর্ড — **অভ্র • প্রভাত / জাতীয় • English** একসাথে।

## 🛠️ যা দিয়ে তৈরি
- 🟣 Kotlin + Android SDK (`InputMethodService`)
- 🧱 Gradle + GitHub Actions
- 🎙️ Android `SpeechRecognizer` (ভয়েস টাইপিং)
- 😊 Android ICU (ইমোজি নাম ও সার্চ)

## ✨ ফিচার
- ↔️ স্পেসবার স্লাইডে ভাষা বদল: English → অভ্র → প্রভাত (বা জাতীয়, সেটিংসে যেটি চালু)
- 🅿️ প্রভাত লেআউট (শিফটে দ্বিতীয় অক্ষর) ও 🇧🇩 জাতীয় লেআউট (বর্ণমালা ক্রমে)
- 💡 শব্দ সাজেশন ও পরের শব্দের অনুমান (অফলাইন, নিজে শেখে)
- 🎤 ভয়েস টাইপিং
- 😊 সব ইমোজি + বিশেষ চিহ্ন (♡ ★ ✿), সার্চ, স্কিন টোন
- 🔢 নাম্বার/ফোন/তারিখের ঘরে ক্লিক করলে নিজে থেকেই নাম্বার প্যাড; অন্য ঘরে 🔢 বাটনে (০-৯ ও + − * /) এবং ?123-এ সব সিম্বল
- ✂️ x / c / v চেপে ধরলে কাট / কপি / পেস্ট, সাথে স্টাইলিশ পপ-আপ
- 📋 ক্লিপবোর্ড ইতিহাস
- 🔊 ভলিউম বাটনে কার্সর সরানো
- 🎨 ১৭টি থিম, 📏 সাইজ পরিবর্তন
- 🎯 মিস-টাচ কমানোর স্মার্ট টাচ সিস্টেম
